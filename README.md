# 고을 윷판 v0.12

조선 고을을 경영하는 4인 2대2 실시간 윷 보드게임입니다. 닉네임 접속, 방 만들기·빠른 참여, AI 빈자리, 팀·캐릭터 선택·레디, 20라운드를 지원합니다. 진행 중 방은 관전 전용으로 입장할 수 있습니다. 참가자가 나가면 AI가 이어받고 마지막 인간 참가자가 나가면 방이 삭제됩니다.

## 로컬 실행

Node.js 20 이상에서 **게임 시작.cmd**를 더블 클릭하거나 이 폴더에서 **npm run dev**를 실행하세요. 별도 패키지 설치는 필요 없습니다. 같은 PC는 http://127.0.0.1:4173/ 에 접속하고, 같은 네트워크의 다른 사용자는 서버가 출력하는 Network 주소로 접속합니다. 구버전 서버가 켜져 있다면 현재 경기가 끝난 후 종료하고 새 서버를 실행하세요. 서버를 재시작하면 방이 초기화됩니다.

## 검증

- npm test: 게임 규칙·카드·방·관전·권한·타이머·채무 검사
- npm run test:network: 실제 임시 HTTP 서버 접속·공유 상태·관전 권한 검사
- npm run build: 배포 파일·이미지·문법 검사 및 공개 게임 서버 주소 설정

## 소스 구성

- dist/: 배포할 화면·게임 규칙·이미지. 현재 버전은 빌드 없는 정적 화면으로 dist가 소스이기도 합니다. Git에서 제외하면 안 됩니다.
- multiplayer.cjs, network-server.cjs, server.cjs: 별도 상시 실행 게임 서버
- build.cjs, validate.cjs, vercel.json: Vercel 화면 빌드·검증
- *.test.cjs: 회귀 검증
- 기획서.md, 사용 안내.md, GitHub-Vercel 배포 안내.md: 최신 규칙·사용·배포 안내

GitHub에는 이 폴더의 내용을 저장소 루트로 올리면 됩니다. 개발 중간 스크립트·QA 화면·스크린샷·옛 보드·호스팅 식별 정보는 배포 폴더에서 분리했습니다. .gitignore와 .vercelignore는 환경설정·인증서·개인 로컬 파일을 제외합니다. .env.example은 공개 설정 예시이며 자동으로 읽지 않습니다.

Vercel은 화면을 배포하고 게임은 별도 HTTPS Node 서버에서 실행합니다. Vercel 환경변수 **GOEUL_API_BASE**에 게임 서버 Origin을 지정하고, 게임 서버 **ALLOWED_ORIGINS**에 Vercel 화면 Origin을 지정하세요. 상세 절차는 **GitHub-Vercel 배포 안내.md**에 있습니다. 방은 현재 단일 서버 메모리에 보관하므로 서버 재시작 후 복원은 지원하지 않습니다.
